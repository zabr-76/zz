🚀 Introducción a z-jackett.js

z-jackett.js es un framework JavaScript reactivo y minimalista que te permite crear interfaces modernas con HTML declarativo. Su sintaxis es sencilla y poderosa.

¿Por qué usar z-jackett.js?

  • Fácil de aprender: Sintaxis intuitiva similar a Vue.js
  • Reactividad automática: Los cambios en los datos se reflejan automáticamente en la UI
  • Sin configuración compleja: Solo incluye el script y comienza a codificar
  • Ligero: Framework minimalista sin dependencias pesadas
  • Flexible: Puedes integrarlo en proyectos existentes

Inicio rápido:

<!DOCTYPE html>
<html>
<head>
    <script src="https://cdn.jsdelivr.net/gh/zabr-76/zz/dist/z-jackett.js"></script>
</head>
<body>
    <div z-app z-data="app()">
        <h1 z-text="message"></h1>
        <button @click="changeMessage()">Cambiar mensaje</button>
    </div>

    <script>
        function app() {
            return {
                message: "¡Hola z-jackett!",
                changeMessage() {
                    this.message = "¡Mensaje cambiado!";
                }
            };
        }
    </script>
</body>
</html>

Código del ejemplo:

<div z-app z-data="forExample()">
    <input type="text" z-model="nuevaTarea" @keyup.enter="agregarTarea()">
    <button @click="agregarTarea()">Agregar</button>
    
    <template z-for="tarea in tareas" :key="tarea.id">
        <div class="task-item">
            <input type="checkbox" z-model="tarea.completada">
            <span z-text="tarea.texto" :class="tarea.completada ? 'completed' : ''"></span>
            <button @click="eliminarTarea(tarea.id)">Eliminar</button>
        </div>
    </template>
</div>

<script>
function forExample() {
    return {
        tareas: [],
        nuevaTarea: '',
        agregarTarea() {
            if (this.nuevaTarea.trim()) {
                this.tareas.push({
                    id: Date.now(),
                    texto: this.nuevaTarea,
                    completada: false
                });
                this.nuevaTarea = '';
            }
        },
        eliminarTarea(id) {
            this.tareas = this.tareas.filter(t => t.id !== id);
        }
    };
}
</script>

🎮 Manejo de Eventos

Los eventos se manejan con la sintaxis @evento y soportan modificadores.

Modificador Descripción Ejemplo
.prevent Previene el comportamiento por defecto @submit.prevent
.stop Detiene la propagación del evento @click.stop
.self Solo se ejecuta si el evento ocurre en el elemento mismo @click.self
.enter Solo con la tecla Enter @keyup.enter
.esc Solo con la tecla Escape @keyup.esc

Propiedades Computadas

Las propiedades computadas son funciones que se recalculan automáticamente cuando cambian sus dependencias.

function app() {
    return {
        precio: 100,
        impuesto: 21,
        descuento: 10,
        
        // Propiedad computada
        precioFinal() {
            const impuestoCalculado = this.precio * (this.impuesto / 100);
            const descuentoCalculado = this.precio * (this.descuento / 100);
            return this.precio + impuestoCalculado - descuentoCalculado;
        }
    };
}

CSS para transiciones:

.fade-enter {
    opacity: 0;
    transform: translateY(-10px);
}

.fade-leave {
    opacity: 1;
    transform: translateY(0);
}

.fade-enter-active {
    opacity: 1;
    transform: translateY(0);
    transition: all 0.5s ease;
}

.fade-leave-active {
    opacity: 0;
    transform: translateY(-10px);
    transition: all 0.5s ease;
}

💡 Mejores Prácticas

Estructura de Proyectos

  • Organiza por componentes: Divide tu aplicación en componentes lógicos
  • Usa propiedades computadas: Para lógica compleja que depende de datos reactivos
  • Mantén los datos planos: Evita anidamientos profundos cuando sea posible

Rendimiento

  • Usa :key en z-for: Para listas dinámicas mejora el rendimiento
  • Evita expresiones complejas en templates: Mueve la lógica a métodos o computadas
  • Usa z-show para toggle frecuente: z-if para condiciones que cambian poco

Depuración

  • Activa el modo debug: window.Z_DEBUG = true;
  • Usa el inspector: Incluye z-inspector.js para desarrollo
  • Console.log estratégico: Para seguir el flujo de datos
